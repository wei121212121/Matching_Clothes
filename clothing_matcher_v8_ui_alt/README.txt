服装找款与配货标注工具 V8 对比界面版
==========================

V8 与 V7 完全独立
-----------------
- V8 不会修改 V7 的程序、索引、设置、预览或本地学习记录。
- 第一次运行 V8 会沿用一次 V7 的图库和结果目录，之后各自保存设置。
- 程序全程离线运行，不需要联网，也不会上传图片。

推荐操作流程
------------
1. 双击 ClothingMatcher_v8.exe。
2. 首次使用选择“款式图库”和“结果目录”，点击“建立/更新索引”。
3. 把微信或资源管理器中的实拍图片拖进左侧；也可复制后按 Ctrl+V，或使用导入按钮。
4. 点击“分析新照片”（F5）。程序只计算新加入、尚未分析的照片，不会重算现有候选或已确认结果。
5. 从左往右检查：实拍图 → 自动识别的颜色/尺码数量 → 右侧 20 款候选。
6. 找到正确款后双击候选，或点“确认候选”。默认会自动进入下一张待确认照片；如需停留查看预览，取消“确认后到下一张”。
7. 前 20 款没有正确结果时点“再显示20款”，列表会直接定位到新增加的第 21 款；可继续增加。
8. AI 没找到时，点“手动选择款式图”；没有可选款时点“未匹配”，程序输出带“未匹配”红字的实拍图。
9. 全部确认后点底部固定按钮“导出本批全部结果”（Ctrl+E）。如仍有未确认照片，程序会先提示，不会悄悄漏掉。

高效操作
--------
- F5：分析新照片。
- Ctrl+Enter：确认当前候选。
- Ctrl+右方向键：下一张待确认。
- Ctrl+左方向键：上一张。
- Ctrl+E：导出本批结果。
- 颜色预设为黑色、白色、灰色、卡其；其他颜色可手输。
- 尺码预设为 M、L、XL、2XL、3XL；只填写数量的尺码才会标红。
- “其他文字”可输入任意内容，回车确认，Shift+回车换行。

V8 匹配方式
-----------
- 使用离线 SSCD 四视角模型：整件、中央图案、上半身、小胸标。
- 自动弱化红色尺码文字，降低它对款式匹配的干扰。
- OCR 识别衣服图案文字；当文字证据可靠时与视觉结果融合。
- 颜色信号被降低，同款不同色仍可匹配。
- 人工确认会成为当前图库的本地实拍样本。难款第一次人工选对后，后续相似实拍会得到额外加权。
- 本地学习最多保留 500 条，只存在 V8 本机缓存；更换图库不会串用。

界面与候选
----------
- 左侧始终显示：总数、待确认、已确认、未匹配。
- 当前图片显示“第几张/共几张”和状态。
- 候选默认直接显示 20 款，并显示“已显示/总款数”。
- 确认、手选、未匹配按钮位于候选图片上方，竖图不会再把按钮顶出屏幕。
- 颜色、尺码数量和其他文字紧跟在确认按钮下方；右侧可直接点“下一张”。
- 两个预览框支持滚轮缩放、左键拖动、双击或“适应窗口”恢复，查看细节不重新分析图片。
- 对比界面版把实拍图和候选/结果图并排放满高度，候选列表与标注操作单独放在最右侧。
- 默认收窄左侧照片队列，给两个竖版预览框更大的显示面积。
- “确认后到下一张”单独换行，避免与候选标题和计数重叠。
- 三条灰色分隔栏带可见手柄；鼠标移上去会显示左右调整光标，预览标题旁也有“↔ 可调宽”提示。
- 颜色和尺码输入会自动换行，在较窄的右侧操作栏中也能完整显示。
- 优先读取实拍图红字中明确写出的颜色；没有颜色文字时才根据衣服画面自动判断。
- 预览空白区域改为浅灰色；拖动时只移动已有画面，不再反复重绘造成闪烁。
- 导出按钮固定在窗口底部，不随图片尺寸移动。
- 小屏幕可使用右侧和底部粗滚动条；候选列表和照片列表也有自己的滚动条。

导出规则
--------
- 原图库和实拍图片不会修改；红字写在结果副本上。
- 匹配结果沿用款式图原文件名，不改名。
- 未匹配结果沿用实拍图原文件名。
- 每批建立“任务001、任务002……”文件夹。
- 同时输出任务总览、任务明细.csv、补货汇总.csv。
- 若还有待确认照片，导出前会显示数量，可返回继续确认或明确忽略。

索引与速度
----------
- V8 的索引、OCR 文字缓存、预览、本地学习均在 ClothingMatcherV8 独立目录。
- 首次建库需计算全部款式；以后图库未变化时直接加载缓存。
- OCR 结果单独缓存。图库只新增少量图片时，旧图不再重复做文字识别。
- 建库后每张实拍只计算一次完整候选；“再显示20款”只展开已有排序，不重复跑模型。
- 红字使用原图绘制，不调用图片生成模型。
