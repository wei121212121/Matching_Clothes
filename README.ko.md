# Matching Clothes | 의류 상품 매칭 및 재고 표기 도구

[简体中文](README.md) | [English](README.en.md) | [한국어](README.ko.md)

Matching Clothes는 매장 실사 사진을 바탕으로 변경 가능한 로컬 상품 이미지 라이브러리에서 같은 상품을 찾는 Windows용 도구입니다. 사진에 빨간색으로 표시된 색상, 사이즈, 수량을 인식하고 사용자가 최종 상품을 확인한 뒤, 표기된 결과 이미지와 작업 명세 및 재입고 집계표를 출력합니다.

프로그램은 기본적으로 로컬에서 동작합니다. 상품 이미지, 실사 사진, 결과물은 업로드되지 않습니다. AI는 후보 순위를 제안하며 최종 매칭은 사용자가 직접 확인합니다.

## 주요 기능

- 전체 의류, 중앙 그래픽, 상반부, 작은 가슴 로고의 네 가지 시점으로 시각적 특징을 비교합니다.
- OCR 문자와 가벼운 질감 특징을 결합하고, 색상은 약한 근거로만 사용하여 다른 색상의 동일 상품도 찾습니다.
- 자동 색상 판단보다 사진의 빨간색 색상·사이즈·수량 표기를 우선 인식합니다.
- 기본 후보 20개를 표시하며 추가 후보 보기와 수동 선택을 지원합니다.
- 두 미리보기 창 모두 마우스 휠 확대/축소, 왼쪽 버튼 드래그, 더블 클릭 초기화를 지원합니다.
- 사용자가 확정한 결과를 현재 이미지 라이브러리 전용 로컬 피드백으로 활용합니다.
- 표기 이미지, 작업 전체 보기, `任务明细.csv`, `补货汇总.csv`를 출력합니다.
- 원본 상품 이미지와 실사 사진은 수정하지 않습니다.

## 빠른 시작

### Windows 무설치 버전

Python 설치 없이 사용하려면 [Windows v8.3 릴리스](https://github.com/wei121212121/Matching_Clothes/releases/tag/v8.3-windows)에서 ZIP을 내려받아 전체 압축을 푼 뒤 `ClothingMatcher_v8_对比界面版_v3.exe`를 실행하십시오. 모델, OCR 구성 요소와 합성 데모가 포함되어 있으므로 EXE만 `_internal` 폴더와 분리하면 안 됩니다.

### 요구 사항

- Windows 10 또는 11
- Python 3.10 이상
- 8GB 이상의 메모리 권장

```powershell
git clone https://github.com/wei121212121/Matching_Clothes.git
cd Matching_Clothes\clothing_matcher_v8_ui_alt
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python app.py
```

ONNX 모델이 없어도 내장된 경량 시각 특징 모드로 실행할 수 있지만 후보 정확도는 낮아집니다. 약 94MB의 호환 모델은 Git 기록에 대용량 파일을 넣지 않도록 별도의 [GitHub Release 파일](https://github.com/wei121212121/Matching_Clothes/releases/tag/model-v1)로 제공합니다. 저장소 루트에서 다음 명령을 실행하면 모델을 올바른 위치에 다운로드하고 SHA-256을 검증합니다.

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\download_model.ps1
```

출처, 라이선스, 체크섬 및 수동 설치 방법은 [모델 설명](docs/模型说明.md)과 [제3자 고지](THIRD_PARTY_NOTICES.md)를 확인하십시오.

### 공개 데모 실행

저장소에는 실제 업무 사진이나 개인정보가 없는 완전 합성 [데모 데이터](examples/README.md)가 포함됩니다.

1. `examples/style_library`를 상품 이미지 라이브러리로 선택합니다.
2. 새 빈 폴더를 결과 폴더로 선택하고 인덱스를 생성하거나 업데이트합니다.
3. `examples/store_photos`를 가져온 뒤 **새 사진 분석(F5)**을 누릅니다.
4. 후보 순위를 `examples/expected_matches.csv`와 비교합니다.

### 첫 실행 순서

1. 상품 이미지 라이브러리와 결과 폴더를 선택합니다.
2. **인덱스 생성/업데이트**를 누릅니다.
3. 실사 사진을 불러오거나 끌어다 놓습니다. 로컬 파일을 복사한 뒤 왼쪽 목록에서 `Ctrl+V`를 눌러도 됩니다.
4. **새 사진 분석(F5)**을 누릅니다.
5. 실사 사진과 후보 미리보기를 비교하고 색상 및 사이즈별 수량을 확인합니다.
6. 올바른 후보를 확정합니다. 라이브러리에 해당 상품이 없으면 **미매칭**을 선택합니다.
7. 모든 사진을 검토한 뒤 **전체 결과 내보내기(Ctrl+E)**를 누릅니다.

## 단축키와 미리보기 조작

| 조작 | 기능 |
| --- | --- |
| `F5` | 새 사진 분석 |
| `Ctrl+Enter` | 현재 후보 확정 |
| `Ctrl+Right` | 다음 미확정 사진으로 이동 |
| `Ctrl+Left` | 이전 사진으로 이동 |
| `Ctrl+E` | 현재 작업 내보내기 |

| 더블 클릭 | 미리보기 창에 맞게 복원 |

## 동일 상품 판단 기준

색상만으로 동일 상품을 판단하지 마십시오. 주요 그래픽과 인물, 안정적으로 보이는 문자, 인쇄 위치, 목둘레, 앞여밈, 주머니, 줄무늬 방향, 특수 질감과 실루엣을 우선 비교합니다. 서로 같은 독특한 특징을 두 가지 이상 확인하거나, 고유한 그래픽/문자와 구조적 특징이 함께 일치할 때 확정하는 것이 좋습니다.

처음 표시되는 20개 후보에 정답이 없으면 20개를 더 표시하거나 수동 선택을 사용하십시오. 이미지 라이브러리에 해당 상품이 없다면 비슷한 상품을 억지로 선택하지 말고 미매칭으로 처리합니다.

## 출력 결과

내보낼 때마다 `任务001`과 같은 독립 작업 폴더가 생성되며 다음 파일이 포함됩니다.

- 확정된 상품의 표기 결과 이미지
- 빨간색으로 미매칭이 표시된 실사 사진 사본
- 작업 전체 보기 이미지
- 사진별 상세 내용을 담은 `任务明细.csv`
- 사이즈별 재입고 수량을 합산한 `补货汇总.csv`

매칭 결과는 상품 라이브러리의 원래 파일명을 유지하고, 미매칭 결과는 실사 사진의 원래 파일명을 유지합니다.

## 개발 및 검증

```powershell
cd clothing_matcher_v8_ui_alt
python -m py_compile app.py engine.py verify_imports.py verify_export.py verify_v8.py
python verify_v8.py
python verify_imports.py
python verify_export.py
```

공개 스모크 테스트용 소형 합성 데모는 저장소에 포함되어 있습니다. 일부 전체 검증 사례는 공개 저장소에 포함되지 않은 더 큰 로컬 테스트 라이브러리가 필요합니다. 구조와 배포 절차는 중국어 [개발 및 패키징 문서](docs/开发与打包.md)를 참고하십시오.

## 정확도 한계

- 선택한 이미지 라이브러리에 없는 상품은 모델이 찾을 수 없습니다.
- 가림이 심하거나 과도하게 잘린 사진, 큰 글자가 상품 이미지를 가리는 경우 정답 순위가 낮아질 수 있습니다.
- 후보 순위는 수동 검색 범위를 줄이는 보조 수단이며 최종 사용자 검토를 대체하지 않습니다.
- 로컬 피드백은 이미지 라이브러리 경로별로 분리되며 다른 라이브러리의 정답으로 사용되지 않습니다.
