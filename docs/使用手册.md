# 使用手册

## 1. 工具用途

本工具用门店实拍图在本地款式图库中寻找同款或同款不同色，并把颜色、尺码数量及补充文字标到确认后的款式图上。它不会修改原图库或实拍图。

## 2. 安装与启动

### 源码运行

在 PowerShell 中进入 `clothing_matcher_v8_ui_alt`：

```powershell
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```

如果 PowerShell 禁止激活脚本，也可以直接运行：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

### 模型

推荐将 `sscd_disc_mixup.onnx` 放到 `clothing_matcher_v8_ui_alt/models/`。没有模型时程序会使用内置轻量方案，功能仍可运行，但匹配质量通常较低。详见 [模型说明](模型说明.md)。

## 3. 标准操作流程

1. 在“款式图库”选择本次要搜索的图片文件夹。
2. 在“结果目录”选择输出位置。
3. 首次使用或图库增删后点击“建立/更新索引”；图库未变化时可直接复用缓存。
4. 导入实拍图：可用按钮、导入整个文件夹、拖放，或复制本地图片后按 `Ctrl+V`。
5. 点击“分析新照片（F5）”。程序只分析新加入且尚未分析的项目。
6. 按“实拍图 → 候选/结果预览 → 候选列表”的顺序核对款式。
7. 找到同款后双击候选，或点击“确认候选”。前 20 款没有正确结果时继续“再显示20款”。
8. AI 排序中没有正确款时点击“手动选择款式图”；图库确实没有时点击“未匹配”。
9. 检查并修改颜色、M/L/XL/2XL/3XL 数量和其他文字。
10. 全部确认后点击底部固定的“导出本批全部结果（Ctrl+E）”。

## 4. 如何判断是不是同款

颜色只作弱证据。同款不同色、模特图与挂拍图、拍摄角度和灯光差异都不应单独否定同款。

优先检查主图案或人物、稳定英文文字、印花位置、领型、门襟、口袋、条纹方向、特殊肌理和版型。建议至少确认两个独特特征一致，或确认“不可替代的主图案/文字 + 版型或领口”一致后再选择。

## 5. 颜色、尺码和文字

- `M2` 表示 M 码 2 件，`XL1` 表示 XL 码 1 件。
- 实拍图中如果有红色人工标注，程序优先读取其中明确的颜色和尺码数量。
- 红字没有颜色时，才根据衣服主体画面自动预填颜色。
- 预填只是建议，可以随时修改。
- 预设颜色包括黑色、白色、灰色、卡其；其他颜色可输入“其他文字”。
- 只有填入数量的尺码才会标在结果图上。
- “其他文字”会原样标注，可用于款号或额外备注。

## 6. 预览与小屏幕操作

- 鼠标滚轮：以指针位置为中心缩放。
- 左键拖动：在放大后移动画面。
- 双击或“适应窗口”：恢复完整显示。
- 灰色竖向分隔栏可左右拖动；鼠标移到分隔栏时会出现调整宽度光标。
- 窗口较小时可使用页面右侧和底部滚动条，导出按钮始终固定在底部。

## 7. 导出内容

每次导出会在结果目录中建立一个独立任务文件夹，例如 `任务001`，其中包含已确认的逐图标注结果、未匹配结果、任务总览图、`任务明细.csv` 和 `补货汇总.csv`。

匹配结果沿用款式图原文件名；未匹配结果沿用实拍图原文件名。导出前若仍有待确认照片，程序会提示返回确认或明确忽略。

## 8. 常见问题

### 启动后匹配引擎显示“轻量视觉特征”

模型没有放到正确目录、文件名不匹配，或 ONNX Runtime 无法加载。检查 `models/sscd_disc_mixup.onnx` 是否存在，再重新启动。

### 第一次建索引很慢

首次需要计算整个图库的特征和 OCR。图库不变时后续会读取缓存；只新增少量图片时会尽量复用旧缓存。

### 正确款不在前 20 个

继续点击“再显示20款”，或使用“手动选择款式图”。不要为了完成任务选择只有颜色相似的款式。

### 拖放无反应

从资源管理器复制图片，然后在左侧按 `Ctrl+V`；也可用“导入实物照片”按钮。

### 要清空 V8 本地设置和缓存

关闭程序后备份并删除 `%LOCALAPPDATA%\ClothingMatcherV8`。这会清除设置、索引和本地反馈，但不会删除图库或结果。不要在程序运行时操作该目录。

## 9. 安全建议

- 公开提交代码前执行 `git status`，确认没有图库、实拍图、结果或模型被暂存。
- 不要把含顾客、员工或门店敏感信息的照片放进公开仓库。
- 不要提交 GitHub Token、网盘分享口令、账号或本机私有路径。
