# 模型说明

## 模型如何提供

视觉模型通常体积较大，而且模型权重有独立许可证。项目继续从 Git 历史中排除 ONNX、PT 和 TorchScript 文件，但把当前兼容的 SSCD ONNX 文件作为独立的 GitHub Release 资源提供：

- 发布页：<https://github.com/wei121212121/Matching_Clothes/releases/tag/model-v1>
- 文件名：`sscd_disc_mixup.onnx`
- 文件大小：98,158,451 字节（约 93.61 MiB）
- SHA-256：`6bd5e2d6e5ecdc077d01dd2353806142c84c9aeea5d3304d581e741802923e4f`

仓库根目录执行以下命令即可自动下载并校验；校验失败时脚本会删除不可信文件：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\download_model.ps1
```

手动下载时，把文件放到 `clothing_matcher_v8_ui_alt/models/sscd_disc_mixup.onnx`，再用 `Get-FileHash` 核对上面的 SHA-256。模型家族来自 Meta SSCD 项目，第三方来源与 MIT 许可全文见 [`THIRD_PARTY_NOTICES.md`](../THIRD_PARTY_NOTICES.md)。本项目提供的是当前应用使用的兼容 ONNX 转换文件，不代表 Meta 对本项目的认可。

## 查找顺序

V8 启动时依次查找：

1. `models/sscd_disc_mixup.onnx`
2. `models/dinov2_small_q4.onnx`
3. `models/vision_model_int8.onnx`

如果都不存在或加载失败，程序回退到内置“轻量视觉特征”。

当前流程针对 SSCD 四视角方案优化，因此推荐使用上述 Release 文件。不要用来源不明的同名模型替换，因为输入输出结构未必兼容。

## 判断是否加载成功

- “SSCD 四视角 + 纹理 + OCR文字融合 V8（CPU）”：SSCD 已加载。
- “DINOv2 Q4 + 纹理组合（CPU）”：DINOv2 已加载。
- “轻量视觉特征”：没有成功加载 ONNX 模型。
