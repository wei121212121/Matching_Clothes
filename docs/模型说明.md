# 模型说明

## 为什么仓库不附带模型

视觉模型通常体积较大，而且模型权重可能有独立许可证。为避免仓库膨胀和未经授权的再分发，本项目会排除 ONNX、PT 和 TorchScript 模型。

## 查找顺序

V8 启动时依次查找：

1. `models/sscd_disc_mixup.onnx`
2. `models/dinov2_small_q4.onnx`
3. `models/vision_model_int8.onnx`

如果都不存在或加载失败，程序回退到内置“轻量视觉特征”。

当前流程针对 SSCD 四视角方案优化，因此推荐使用 `clothing_matcher_v8_ui_alt/models/sscd_disc_mixup.onnx`。请从模型原始发布方或有权使用的内部存储获取模型，并自行确认许可证。本仓库不提供第三方模型下载链接，也不保证任意同名模型的输入输出结构都兼容。

## 判断是否加载成功

- “SSCD 四视角 + 纹理 + OCR文字融合 V8（CPU）”：SSCD 已加载。
- “DINOv2 Q4 + 纹理组合（CPU）”：DINOv2 已加载。
- “轻量视觉特征”：没有成功加载 ONNX 模型。
