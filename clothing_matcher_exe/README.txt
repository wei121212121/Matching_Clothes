服装找款与配货标注工具
========================

用途
----
1. 从款式图库中寻找与门店实物照片相同的衣服款式，允许颜色不同。
2. 识别门店照片上的红色尺码数量，例如 XL2 表示 XL 码 2 件；也允许人工输入任意标注文字。
3. 自动判断衣服颜色，并允许人工修改。
4. 人工确认候选款式后，在参考款式图的副本上直接写入红色“颜色、尺码、数量”。
5. AI 找不到时不再继续复查，直接人工选择款式图并填写颜色、尺码数量或任意自定义文字。
6. 每批自动建立任务编号，导出标注图片、任务总览、任务明细和补货汇总；未选择的照片直接跳过，原始图库不会被修改。

推荐操作流程
------------
首次使用：
1. 运行“服装找款工具.exe”。
2. 选择款式图库文件夹。
3. 点击“建立/更新索引”，首次建立后会缓存；以后只有图库变化才需更新。
4. 选择结果保存目录。

日常使用：
1. 把图片或文件夹直接拖进左侧白框；也可以先复制文件，再点左侧白框按 Ctrl+V。按钮导入仍然可用。
2. 点击“分析全部”。
3. 逐张检查自动颜色、尺码数量及右侧初检候选款式。
4. 双击正确候选，或者点击“手动选择款式图”。
5. AI 候选没有正确款式时，直接点击“手动选择款式图”，再人工修改颜色和标注文字。
6. 在“标注文字”框输入任意内容；普通回车保存，Shift+回车换行。
7. 点击“导出本批全部结果”。

结果目录
--------
每批次会在“标注结果”中新建“任务001、任务002……”文件夹，里面包含：
- 每件确认款：`任务001_图片01_初检确认_款式名_标注.png`。
- `任务001_总览.jpg`：按图片顺序展示已经确认并导出的结果。
- `任务明细.csv`：逐张记录编号、确认阶段、颜色、尺码数量和绝对路径。
- `补货汇总.csv`：按款式、颜色和尺码合计数量。

业务规则
--------
- 颜色不同不影响款式匹配。
- 图库中的“_标注”图片和“标注结果”文件夹不会进入索引。
- 文件名中的状态文字不会阻止导出，是否进货由人工判断。
- 每张门店照片始终保留独立图片编号，即使是同款不同颜色。
- 同款同色的数量只在“补货汇总.csv”中合计，不合并或覆盖结果图片。
- 没有尺码数量时显示“无尺码数量”，不会猜测数量。
- “标注文字”不限制尺码格式，例如“成人款 3件”“备用文字”也会原样写成红字。
- AI 找不到时不做二次复查；人工选择款式图即可。没有人工选择的照片不导出、不继续处理。
- 红字位置会在多个区域中选择细节较少的位置，尽量避开衣服主图案。

速度说明
--------
- 首次建库需要读取全部款式图；以后直接加载缓存。
- 建库以后，每张门店照片只需计算一次特征并与缓存比较。
- 红字是在原参考图副本上直接绘制，不使用图片生成，所以很快。
